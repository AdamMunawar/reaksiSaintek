# LPM Reaksi Portal - Application Core

Aplikasi web portal berita resmi LPM Reaksi FST UIN Sunan Gunung Djati Bandung berbasis Next.js 16 App Router & Tailwind CSS.

## Perintah Utama
* `npm run dev` : Menjalankan development server di `http://localhost:3000`
* `npm run build`: Membangun bundle produksi untuk deployment Vercel
* `npm run start`: Menjalankan server produksi hasil build
* `npm run lint` : Memeriksa standar kode ESLint

Dokumentasi lengkap dan panduan arsitektur terdapat di [README.md](../README.md) utama.
